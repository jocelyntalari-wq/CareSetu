# CareSetu Flutter Mobile Application

> **“Your health story, connected to better care.”**

This folder contains the Flutter cross-platform mobile application for **CareSetu** (Android, iOS, Web).

## 🚀 Quick Start

### 1. Install Dependencies
```bash
flutter pub get
```

### 2. Run on Web (Chrome)
```bash
flutter run -d chrome
```

### 3. Run on Mobile Device or Emulator
```bash
flutter run
```

---

## 📌 Features & Architecture

- **Guided Patient Intake:** Step-by-step health story entry for General Medicine & Ayurveda.
- **Multilingual UI:** Audio-assisted intake in English, Hindi (हिंदी), and Telugu (తెలుగు).
- **Document Locker:** Camera document capture and report preview.
- **Doctor Summary Bridge:** 1-Page clinical draft generation.
- **Emergency SOS:** Direct emergency telephone triggers and safety notices.

For full project documentation, API keys setup, backend configuration, and screen specifications, see the main [CareSetu README](../README.md).
